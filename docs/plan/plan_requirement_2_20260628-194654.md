## 五、进入真实小样本的前置条件

在加载真实数据前，必须满足以下全部条件：

1. ✅ 环境检查通过（`python_version_ok=true`、`ready_for_cli_runtime=true`）
2. ⏳ 明确官方或授权来源页面 + 引用/使用说明确认
3. ⏳ source review approval review → `ready_for_registry_update=true`
4. ⏳ registry update plan → `ready_for_registry_patch=true`
5. ⏳ registry patch preview → 人工确认 `patched_source`
6. ⏳ source snapshot planning review → `ready_for_snapshot_planning=true`
7. ⏳ 原始文件保存到 raw snapshot 目录
8. ⏳ `manifest.json` 生成
9. ⏳ 人工整理 5-20 行样本
10. ⏳ parser rows bundle smoke → `ready_for_parser=true`
11. ⏳ quality smoke → `ready_for_quality_gate=true`
12. ⏳ dry-run → `load_ready=true`、`blockers=[]`
13. ⏳ loader approval packet 存在并通过复核
14. ⏳ artifact manifest → `ready_for_loader_execution=true`
15. ⏳ answer source policy review → `answer_mode != unsupported`
16. ⏳ Agent visibility activation review → `ready_for_agent_visibility=true`
